# Contributing

Thank you for using hotserve, and for wanting to help. Bug reports,
questions and ideas are all welcome. They start in
[Discussions](https://github.com/smallhoursorg/hotserve/discussions),
not in issues or pull requests:

- **Something broke, or you are stuck** — post in
  [Q&A](https://github.com/smallhoursorg/hotserve/discussions/new?category=q-a).
  The form asks for your version and a journal excerpt.
- **An idea** — post in
  [Ideas](https://github.com/smallhoursorg/hotserve/discussions/new?category=ideas).
- **A security problem** — never in public. Follow
  [SECURITY.md](SECURITY.md).

Issues are the maintainer's work queue. When a discussion turns into
something concrete to fix or build, the maintainer opens the issue and
links it, so every open issue is ready to work on.

## Pull requests

hotserve is open source, not open contribution. It is maintained by
one person, and it runs as a system service in front of every site on
the box, so even a one-line change needs careful testing. Pull requests are therefore limited to
collaborators. If you have a fix, describe it in a discussion. A diff
in a discussion is welcome, and if it fits, the maintainer makes the
change.

Forks are welcome under the [Apache-2.0 licence](LICENSE).
